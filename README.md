# Baldur

Baldur is a desktop manga reader for macOS and Windows, built by [kill4n](https://github.com/kill4n).

This repository hosts the **public releases** of the app. Grab the latest installer from the
[Releases](https://github.com/kill4n/baldur-releases/releases/latest) page.

## Downloads

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `Baldur_<version>_aarch64.dmg` |
| macOS (Intel) | `Baldur_<version>_x64.dmg` |
| Windows (installer) | `Baldur_<version>_x64-setup.exe` |
| Windows (MSI) | `Baldur_<version>_x64_en-US.msi` |

## Installing

The installers are not code-signed yet.

- **macOS:** if the app is blocked on first launch, open *System Settings › Privacy & Security* and choose *Open Anyway*.
- **Windows:** if Microsoft Defender SmartScreen appears, click *More info › Run anyway*.

## Features

- Read manga from online sources, with chapter downloads and exports.
- Library with unread counts, new-chapter notifications and background sync.
- Resume reading exactly where you left off.
- Light, dark and system themes.
